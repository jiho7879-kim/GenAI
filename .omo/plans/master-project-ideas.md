# Final Project 아이디어 v2 — 석사 2년간 쓸 Research Assistant

> **대상**: 내년 석사 입학 예정 (2027~2029, 2년 과정)  
> **목표**: 과정에서 배운 Transformer/RAG/Multi-Agent/Streamlit 기술로  
> **2년간 실제 연구에 매일 사용할 수 있는 서비스** 개발  
> **환경**: CPU-only 노트북 (32GB RAM), Ollama local, Zen Free Hybrid

---

## 🎯 석사생의 2년 — 페인 포인트

```
1 학기 (수업+연구주제탐색)    2 학기 (본격연구+실험)       3~4 학기 (논문작성+졸업)
        │                           │                           │
        ▼                           ▼                           ▼
  • 논문 100편 읽어야 함      • 실험 반복 (실패의 연속)    • 논문 구조 잡기 어려움
  • 읽은 거 또 까먹음          • 결과 정리 엉망            • 레퍼런스 관리 지옥
  • 연구 주제 못 정하겠음      • 선행연구와 비교 어려움     • 쓰다 지움 반복
  • 교수님: "최신 트렌드 봤어?" • 인사이트 도출 실패        • "이거 어디서 봤더라..."
```

**공통점: 정보 과부하 + 반복 작업 + 지식 증발**

### 1. 🔥 Top Pick: Arxiv Research Agent (내 연구실 커스텀 Assistant)

**컨셉**: "내 연구 분야 논문을 **읽고, 정리하고, 연결하고, 써주는** 개인 연구 비서"

**2년 사용 시나리오**:

| 시기 | 사용 예 |
|---|---|
| **1학기** | "Transformer 변천사 정리해줘" → RAG로 50편 요약 → 타임라인 시각화 |
| **2학기** | "내 실험 결과(CSV)랑 관련 있는 논문 찾아줘" → 유사 방법론 검색 → 비교분석 |
| **3학기** | "이 방법론의 limitation을 5편 논문에서 찾아줘" → Agent가 각 논문 스캔 |
| **4학기** | "Related Work 초안 작성해줘 (내 연구와의 차별점 포함)" → Multi-Agent 초안 생성 |

#### 주요 기능 (MVP → 2년 확장 로드맵)

| Phase | 기능 | 기술 |
|---|---|---|
| **MVP** (3일) | 논문 PDF 업로드 → 요약 + Q&A | Langchain RAG, Ollama, Streamlit |
| **1개월차** | Arxiv 자동 수집 (키워드 알림) | Arxiv API, 스케줄러 |
| **3개월차** | 논문 간 연결 그래프 (인용/유사도) | NetworkX 시각화 |
| **6개월차** | 실험 로그 연동 (CSV → 논문 비교) | Pandas Agent |
| **1년차** | Related Work 자동 초안 작성 | Multi-Agent pipeline |
| **1.5년차** | LaTeX 템플릿 + 인용 포맷 자동생성 | BibTeX 파싱 |
| **2년차** | 전체 논문 구조 제안 + 리뷰 | Feedback loop |

#### CPU-only 에서의 동작

| 작업 | 사용 모델 | 예상 시간 |
|---|---|---|

> 석사 졸업 시점에는 **"내 연구만큼은 누구보다 잘 아는 AI"** 가 완성됨.

### 2. 📚 대안: Personal Research Wiki (지식축적 Agent)

**컨셉**: "읽은 논문, 실험 결과, 교수님 피드백, 내 생각을 **구조화된 개인 위키**로 자동 정리"

#### 핵심 기능
- 논문 읽을 때마다 자동으로 Wiki 페이지 생성
- 실험할 때마다 자동으로 로그 기록
- 검색하면 내 연구 전체를 한 번에 조회

#### 2년 후 결과물
```
📖 내 연구 분야 개인 백과사전 (Notion + AI)
  - 200편 논문 요약 (내 언어로)
  - 50회 실험 로그 (결과 + 해석)
  - 30개 아이디어 노트 (기술적 검토 포함)
  - Related Work 3개 초안
```

### 3. 🎓 대안: 석사 일정 & 연구 코디네이터

**컨셉**: 2년 석사 일정을 관리해주는 Agent

#### 핵심 기능
- **연구 마일스톤 트래킹**: "1학기: 논문 20편 읽기" → 진행률 자동 체크
- **논문 디스커버리**: 설정한 키워드의 최신 논문 매일 요약推送
- **컨퍼런스 데드라인**: 학회 제출 일정 알림 + 템플릿 제공
- **지도교수 미팅**: "이번주 미팅에서 다룰 내용을 정리해줘" → 지난주 논의 + 금주 진료

### 4. 🔬 대안: 논문 실험 재현 및 분석 파이프라인

**컨셉**: "이 논문의 실험을 **내 데이터로 재현**해보고 결과를 비교해주는 시스템"

#### 시나리오
```
1. 논문 업로드 → 핵심 실험 설정 (데이터셋, 하이퍼파라미터) 추출
2. 내 데이터셋 설명 입력 → Agent가 실험 코드 스켈레톤 생성
3. 실험 결과 CSV 업로드 → 논문 결과와 비교 시각화
4. "왜 내 결과가 논문보다 낮지?" → 원인 분석 Agent
```
